# VMC Spatial Studio · Editor en vivo (tipo Sims)

Gemelo espacial editable del **Piso 16 (VMC)** de YPF. R3F + Drei.

## 🎮 Editor en vivo
- **Editar 2D/3D:** arrastrás los objetos por el piso (raycast directo / drag SVG).
- **Paleta:** agregás islas, mesas redondas, comedores y oficinas.
- **Barra flotante:** rotar ±15°, ±par, duplicar, borrar (o tecla Del).
- **Inspector:** redimensión en vivo (pares, radio, ancho/profundidad), rotación, color.
- **Grilla magnética (snap 250 mm)** on/off. Autosave + exportar/importar JSON.

Las 12 islas base salieron del plano oficial por visión computacional.

## 🧱 Stack
Vite + React + TS + @react-three/fiber + @react-three/drei + three. Build en Vercel.
